# Demo cartridges — v0.6.0

The ZIP contains all 11 BIN files supplied in the local DemoCarts collection,
renamed to identify each picture. Their bytes are unchanged; SHA-256 values and
mode names are recorded in manifest.json. Open these NTSC images in Stella.
They are earlier exported examples, not conversions regenerated for v0.6.0.

Cyberwoman and Escher are BUS2 demo cartridges and include the runtime support
needed by those supplied ROMs. Their BUS technique and driver originate with
Chris Walton / cd-w and Darrell Spice Jr. / SpiceWare. See BUS-RESEARCH.md and
CREDITS.md. Other cartridge types in this set are 4K, F8, F6 and EF. Physical
console and cartridge compatibility has not been established for this collection.

The demonstration artwork remains the work of its respective creators. Inclusion
as conversion examples does not grant a new license to that artwork. The source
and Windows software packages keep optional cartridge drivers separate.
