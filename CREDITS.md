# Provenance and acknowledgements

`chrono/resources/kernel.asm` is a preserved copy of the recovered Chrono2 `GreetingCart.asm`. Its header identifies Andrew Davie's Interleaved Chronocolour work, Copyright (C) 2003, and acknowledges Eckhard Stohlberg and Thomas Jentzsch. The original header requests acknowledgement in documentation accompanying ROMs using the system. It remains in generated assembly, and exports include a README with these credits.

`frametable.asm` follows the recovered three-frame table. `ntsc.json` transcribes the 128 RGB/color-code DATA entries in the recovered `Chrono2V2/Chrono2.bas`. The binary template is assembled from the preserved kernel with black image data and zero color operands; its hash and operand offsets are recorded in `kernel-patches.json`.

The Python conversion model follows Chris Martin's Chrono2 component mixtures, pixel-index mapping, bottom-up sprite packing and palette-search approach. New GUI controls and the weighted search are described in README.md. The built-in calibration image is generated by this project; no historical third-party image samples are distributed here.

The public source does not include the original ZIP image collections or DASM executable. No blanket license is applied to this mixed historical source without the owner's decision. Original notices govern their respective material.

## Raster extensions (0.2.0 development)

`chrono/raster_rom.py` generates separate 48-pixel and asymmetric 40-pixel kernels. The 48-pixel multiplex sequence derives from the preserved, credited Davie kernel; its fixed-address loads and per-row color schedule are new. New exported assembly and the accompanying README credit Davie, Stohlberg and Jentzsch. The playfield kernel uses new timing and packing code. Its research sources, including Michael Martin's 48-pixel explanation and Andrew Davie's asymmetric playfield tutorial, are linked in RESEARCH.md. No new blanket license is asserted over these derivatives.

`chrono/playfield_plus.py` is the new unrolled F6 score-mode playfield implementation. It uses Atari register behavior documented in RESEARCH.md; the original Chronocolour kernel is unchanged.


## BUS extension (0.2.2 development)

The unchanged 2 KiB BUS2 driver is extracted from `128bus_20170120.bin` supplied with the official Stella 7.0 source archive. BUS-RESEARCH.md records its hash and download source. The original demo's pictures and application code are not included. `chrono/bus_rom.py` generates a new Thumb initializer and 6507 background-raster kernel. Stella's BUS mapper source and Darrell Spice Jr.'s technical presentation informed the implementation. Separate driver redistribution terms have not been established; no blanket license over that binary is asserted. The public package excludes this driver and its embedded copies; setup retrieves and verifies the original upstream bytes locally. No new redistribution rights are asserted.

## Atari 2600 Image Optimizer 0.4.0

This is the new application name for the maintained Python continuation of Chrono2. Original author credits and historical filenames are preserved. Public ROM templates reserve zero-filled slots for externally obtained BUS/DPC+/CDFJ+ drivers; setup fetches them from the pinned sources recorded in chrono/drivers.py. No such driver bytes or full driver-bearing assembly templates are distributed by this repository.
